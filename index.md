# ARIEL - Privacy Policy

ARIEL is a private, personal assistant app built and used by one person for their own use. It is not offered to the public.

## What it accesses

With the owner's explicit consent, ARIEL uses Google's Gmail API with the read-only scope (gmail.readonly) to read the owner's own Gmail accounts, so the owner can ask for summaries of their own email.

## What it does with the data

- It only reads. It cannot send, modify or delete any email.
- - Email content is read on demand, on the owner's own computer, to answer the owner's own questions.
  - - Email data is not sold, shared with third parties, or used for advertising.
    - - Only a Google authorization token is stored, locally on the owner's computer. Email content is not stored.
     
      - ## Revoking access
     
      - Access can be revoked at any time at https://myaccount.google.com/permissions
